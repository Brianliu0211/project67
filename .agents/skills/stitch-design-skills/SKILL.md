# Stitch Design Skills - Google Open Agent Standard

## Trigger Conditions
Triggers during architectural design, state management setup, and cross-developer module synchronization.

## Directives
1. **SSOT Spec Alignment**: Ensure all system components inherit design tokens from `app_settings.dart` and `main_spec.md`.
2. **Modular Decoupling**: Keep UI components independent so developers (Lobo & Beast) can modify screens without code collisions.
