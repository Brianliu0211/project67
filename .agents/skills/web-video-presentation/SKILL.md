# Web Video Presentation - Guided Tour & Demo Standard

## Trigger Conditions
Triggers whenever coding onboarding tours, feature walkthroughs, interactive spotlight coachmarks, or product video presentation overlays.

## Directives
1. **Spotlight Hole Cutout (Interactive Overlay)**:
   - Darken the background screen while preserving 100% opacity and full clickability on the highlighted target element.
2. **True Event Triggering**:
   - Force the user to click the actual target component (e.g. FAB or Tab) to trigger real UI state changes and advance to the next step.
3. **Segmented Progress Indicators**:
   - Render segmented progress bars (`— — — —`) showing step progression.
4. **Replay Controller**:
   - Provide full replay entry points inside `settings_screen.dart`.
