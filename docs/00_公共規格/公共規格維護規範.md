# 📐 公共規格維護與撰寫標準 (Meta-Specification)

本文件為 `insurance_helper` 專案 `docs/00_公共規格/` 目錄之最高指導規範（規範的規範）。旨在確保所有規格文件具備統一的結構、清晰的單一職責、零重複性與長期的高可維護性。

---

## 📌 一、 單一真實來源原則 (Single Source of Truth, SSOT)

1. **獨特職責**：`docs/00_公共規格/` 下的每一份文件必須具備明確且唯一的領域職責，嚴禁跨檔案重複撰寫相同的具體條文。
2. **交叉引用**：若 A 文件需提及 B 文件的內容，必須以 Markdown 相對路徑超連結引用，不得複製貼上內文。

## 📝 二、 標準規格文件Markdown 模板 (Standard Spec Template)

未來新增或重構 `docs/00_公共規格/` 中的任何文件時，必須採用以下 5 個標準區塊：

```markdown
# 📐 [規範名稱]

## 📌 一、 核心宗旨 (Purpose & Scope)
- 說明本規範成立的目的與解決的問題。

## 🎯 二、 適用對象與觸發時機 (Target & Trigger)
- 說明誰在什麼時候必須遵循本規範。

## 🛠️ 三、 具體條款與 SOP 流程 (Rules & SOP)
- 條列式極簡寫出規範細節（避免空話）。

## 🔗 四、 關聯連動檔案 (Dependencies)
- 列出修改本規範時，必須同步更新的其他檔案清單。

## 📜 五、 異動紀錄 (Changelog)
- 紀錄規範新增或修訂的日期與摘要。
```

## ✂️ 三、 規範瘦身與歸檔機制 (Pruning & Archiving)

1. **定期巡檢**：於階段性收工或專案里程碑時，檢查 `docs/00_公共規格/` 是否有內容重疊或過時之文件。
2. **歷史歸檔**：若某份規範過時或已被全新規範完全取代，不直接刪除，而是移至 `docs/00_公共規格/歷史歸檔/` 目錄中，維持公共規格區永遠只有最新、最精準的有效文件。
