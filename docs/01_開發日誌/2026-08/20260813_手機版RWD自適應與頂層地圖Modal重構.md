## 📝 變更範疇與邏輯說明

### 1. 右上角通知鈴鐺 Icon 顏色與顯示修復 (`lib/screens/home_screen.dart`)
- **問題根因**：手機端 `AppBar` 為深色底 (`#0D1117`)，但在 Light Theme 模式下圖示繼承了 `Colors.black87`，導致黑色 Icon 印在黑底上完全無法辨識；加上 Flutter Web Release 的 Font Tree-shaking 誤裁了圖示。
- **解決方案**：
  - 手機端 `AppBar` 將標題、`iconTheme` 與通知 Icon 綁定主題動態 `textColor`（黑底用白色，白底用黑色）。
  - 編譯流程帶入 `--no-tree-shake-icons` 參數，防止 Web Release 誤裁 MaterialIcons 字型庫。

### 2. 客戶管理頂欄與 3D 卡片觸控修復 (`lib/screens/customer_management_tab.dart`)
- **頂欄按鈕**：於手機端將「批次匯入」、「批量管理」、「新增客戶」切換為自適應 `Wrap` 換列。
- **3D 翻轉卡片**：於 `FlippingCustomerCard` 頂層包覆 `GestureDetector(behavior: HitTestBehavior.opaque)` 確保觸控屏點擊手勢 100% 捕獲，並將手機 GridView `childAspectRatio` 調至 `1.65`。

### 3. 數據戰情室指標卡片橫向排版修復 (`lib/screens/data_dashboard_tab.dart`)
- 在 `< 600px` 手機端將頂部 3 個指標卡片由橫向 Row 切換為上下單欄 Column 滿版展演，並加入 `maxLines: 1` 與 `TextOverflow.ellipsis`，徹底消除直排文字。

### 4. 新聞頭條頂欄、Modal 與卡片按鈕修復 (`lib/screens/insurance_news_tab.dart`)
- 大勢總覽彈窗 Header 與新聞卡片底部按鈕於手機端切換為自適應 `Wrap` / `Column` 排版，確保更新時間與按鈕文字無裁切。

### 5. 系統設定客戶卡片檢視偏好標籤修復 (`lib/screens/settings_screen.dart`)
- 手機端將 `SegmentedButton` 切換為垂直單欄佈局與 `double.infinity` 寬度，徹底平展標籤文字。

### 6. 新增行程頂層互動式地圖 Modal 重構 (`lib/widgets/schedule_event_dialog.dart`)
- **問題根因**：原本點擊地圖按鈕時在 Dialog 表單內擠壓展開，導致手機端畫面擠爆。
- **解決方案**：實作 `_openInteractiveMapModal` 頂層彈窗。點擊地圖圖示時，地圖直接彈出至最上方層級（100% 蓋過底層表單 UI），提供寬敞獨立的搜尋、點擊與「📍 確認套用此地點」帶回功能，保持底層行程表單 100% 單欄優雅排版。
