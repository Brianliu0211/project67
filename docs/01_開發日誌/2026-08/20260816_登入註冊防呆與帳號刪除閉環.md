# 📅 [2026-08-16] - 【模組一：基礎建設與安全防護】登入註冊防呆、重設密碼獨立頁面與軟刪除閉環

> **執行狀態**：🟢 已併入特徵分支 (`feature/lobo-auth-repair`)

## 🎯 實作成果摘要
- 全面修復註冊/登入流程中的 7 項操作體驗問題（包含未註冊錯誤提示、密碼防窺眼睛按鈕、姓名自動填入移除、註冊成功直達信箱按鈕、預設角色修復）。
- 將「重設密碼」重構為獨立全螢幕頁面（`ResetPasswordScreen`），杜絕繞過直接進後台的資安隱患，並在重設完成後強制銷毀臨時 Session 登出，要求使用者以新密碼手動登入。
- 建立帳號「軟刪除 (Soft Delete)」與開發者面板「實體清理 (Hard Delete)」閉環，並同步遠端 Supabase `profiles` 資料表結構（新增 `status` 與 `role` 欄位及 RLS 安全政策）。

## 💻 技術變更明細 (Actual Technical Changes)
- **[NEW] `lib/screens/reset_password_screen.dart`**：
  - 建立全螢幕無干擾的密碼重設卡片，具備密碼與確認密碼雙欄位校驗、眼睛防窺切換、例外捕獲與強制登出機制：
    ```dart
    await Supabase.instance.client.auth.updateUser(UserAttributes(password: newPassword));
    await Supabase.instance.client.auth.signOut();
    CustomToast.show(context, '密碼重設成功！請使用新密碼重新登入。', ToastType.success);
    widget.onCompleted();
    ```
- **[MODIFY] `lib/main.dart`**：
  - 於 `AuthGateway` 攔截 `AuthChangeEvent.passwordRecovery` 事件，路由直接導向 `ResetPasswordScreen`，不載入任何後台 UI 或側邊欄。
- **[MODIFY] `lib/screens/login_screen.dart`**：
  - 修正未註冊帳號登入錯誤訊息；新增密碼可視切換按鈕；移除註冊時自動填入姓名的邏輯；於註冊成功對話框新增「前往收件匣 (開啟信箱)」外部跳轉按鈕；`enable_auto_approval` 預設改為 `false`。
- **[MODIFY] `lib/screens/home_screen.dart`**：
  - 修正 `_userRole` 與 `_activeViewRole` 預設值為 `UserRole.agent`，修復註冊驗證後直通進入開發者模式的路由錯誤。
- **[MODIFY] `lib/screens/settings_screen.dart`**：
  - 於設定頁底部新增【刪除帳號】區塊，點擊後跳出確認警告，將 `profiles.status` 更新為 `deleted` 並執行登出。
- **[MODIFY] `lib/screens/dev_console_screen.dart`**：
  - 於開發者面板新增「用戶資料清理與實體刪除 (Hard Delete)」區塊，列出所有 `status = deleted` 的使用者，支援開發者一鍵實體清除。
- **[MODIFY] `lib/services/app_localizations.dart`**：
  - 更新中英文忘記密碼提示語系為「若此信箱已經註冊，重設密碼連結將會寄至您的信箱。」以保護未註冊信箱隱私。
- **[DB / Schema] `Supabase Profiles Table & RLS`**：
  - 執行 `ALTER TABLE public.profiles ADD COLUMN IF NOT EXISTS status TEXT NOT NULL DEFAULT 'active';` 與 `role` 欄位新增。
  - 配置 `SELECT`、`UPDATE`、`DELETE` 之 RLS 政策，並發送 `NOTIFY pgrst, 'reload schema'` 刷新 PostgREST API 快取。
