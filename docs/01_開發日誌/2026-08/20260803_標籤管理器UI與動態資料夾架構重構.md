# 📅 [2026-08-03] - 【模組五：系統個性化】標籤管理器 UI 與動態資料夾架構重構

> **執行狀態**：🟢 已併入主線 (src)

## 🎯 實作成果摘要
本階段完成標籤系統的全新架構與 UI 落地，採用「動態資料夾 (Dynamic Folders) 架構」解決標籤擴充性與 AI 歸類問題。實作大分類 5 大資料夾、顏色繼承與自訂色盤、同名標籤防呆、一鍵標籤合併（自動連動全站客戶檔案）、客戶表單的「折疊式大標籤選取器」以及標籤管理器「子彈窗對話框模式」。

---

## 💻 技術變更明細 (Actual Technical Changes)

- **[NEW] `lib/services/tag_manager_service.dart`**：
  - 實作 `TagCategoryModel` 與 `TagItemModel` 資料模型。
  - 提供 `getCategories()`, `getTags()`, `addCategory()`, `addTag()`, `editTag()`, `deleteTag()` 等完整 CRUD。
  - 實作 `mergeTags(targetTagName, sourceTagNames)`：批次移除舊標籤並同步連動 Supabase `customers` 表中含有舊標籤之所有客戶紀錄。
  - 實作 `isTagNameExists(name)` 防範同名標籤重複建立。

- **[NEW] `lib/screens/tag_manager_screen.dart`**：
  - 實作標籤管理器介面，支援 5 大資料夾 Tab 切換、子標籤網格展演與多標籤勾選合併。
  - 支援 `isDialogMode` 模式與 `TagManagerScreen.showAsDialog(context)` 靜態調用，點擊從表單以 200ms 對話框彈窗開啟，避免全畫面推頁過於突兀。

- **[MODIFY] `lib/screens/settings_screen.dart`**：
  - 在設定頁面新增「🏷️ 標籤字典與資料夾管理」獨立入口 ListTile 卡片。

- **[MODIFY] `lib/screens/customer_management_tab.dart`**：
  - 新增 `CategorizedTagAccordionSelector` 元件：將常用標籤按 5 大資料夾包裝為 1 鍵展開/折疊的膠囊列，解決標籤佔滿表單頁面的問題。
  - 標籤文字與外距全面放大 2 倍 (14px/15px 加粗)，並依據 `TagCategorizer` 分類主題色顯示。
  - 新增 `_openQuickAddTagDialog`：在客戶表單中提供一鍵新增標籤與 7 色自訂色盤選取對話框。
  - 新增 `_showShareExportModal`：提供一鍵生成 Excel/CSV、vCard 通訊錄 (.vcf) 與 PDF 客戶報表之微縮放動畫彈窗。
