# 開發日誌：客戶雙維度人脈關係與動態拓撲網絡重構

---

## 🎯 核心改進與功能描述

1. **資料庫 Schema 與 RLS 權限建置**：
   - 新增 `supabase/migrations/20260813_create_customer_relationships.sql` 遷移檔。
   - 建立 `public.customer_relationships` 資料表，支援 `source_customer_id`與 `target_customer_id` 的角色型社交關係（`family`, `workplace`, `social`, `other`）與 `relationship_detail` 文字說明。
   - 配置 strict RLS 安全政策，強制使用 `(SELECT auth.uid()) = user_id` 作為防護。

2. **客戶詳情卡片背面（雙維度關聯管理 UX）**：
   - 修改 `lib/screens/customer_management_tab.dart` 中 `FlippingCustomerCard` 卡片背面與放大對話框。
   - 新增 `👥 人脈與轉介紹關聯` 按鈕，點擊彈出互動選單：
     - **維度 1（轉介紹歸因）**：動態指定/更換轉介紹人（`referral_source_id`）。
     - **維度 2（社交角色關係）**：動態新增/刪除親眷、職場、社團關係與細節描述（如 "夫妻"、"同事"）。

3. **黑曜石 (Obsidian) 動態網絡拓撲繪圖引擎升級**：
   - 重構 `lib/screens/relationship_topology_tab.dart`：
     - **子圖連通分量群島演算法 (Cluster Island Layout)**：運用 BFS 連通分量演算法，將主要網絡聚攏於中央，獨立小組（如 5-6 夫妻檔）自動排在獨立群島分區，解決獨立連線橫跨中央問題。
     - **相鄰角度聚類排序 (Greedy Adjacent Angular Sorting)**：外圍節點按相鄰關聯度進行角度順序聚類，消滅斜對角交錯線段。
     - **雙向規範化向量與對稱避讓弧線 (Canonical Symmetric Opposing Arches)**：將兩點間的多重關係以標準化 ID 向量做對稱方向解耦，展現 90px~100px 橢圓雙弧線。
     - **單向轉介紹箭頭與標籤防重疊 (Directional Referral Arrows & Avatar Margin Protection)**：轉介紹線段加載單向箭頭，標籤膠囊實施 55px 外圍安全距保護。
