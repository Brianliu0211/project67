## 🎯 實作成果摘要
重構 Auth 註冊頁面 UX 與 Supabase 驗證邏輯，徹底解決註冊時「邀請碼與角色被清空/卡死」、「未驗證 Session 死結」以及「`otp_expired` 信件驗證連結過期」問題。將註冊表單簡化為僅需填寫「姓名（綽號）」、「Email」與「密碼」3 欄，並補齊前端過期網址自動攔截與一鍵重發驗證信功能。

  - **URL 查詢參數過期捕獲 (`_checkUrlErrors`)**：在 `initState` 中檢測 Web URL Query Parameters (`error_code == 'otp_expired'`)，自動跳出黃色警示提示點擊最新信件。
  - **一鍵重發驗證信**：於 `AuthException` (`Email not confirmed`) 捕獲點，整合 `CustomToast` 並提供 `actionLabel: '重發驗證信'` 觸發 `supabase.auth.resend(type: OtpType.signup, email: email)`。
  ```dart
  // 檢測 URL 過期 parameters
  if (errorCode == 'otp_expired' || (error != null && error.isNotEmpty)) {
    CustomToast.show(
      context,
      '⚠️ 驗證連結已過期或失效！若您收到了多封驗證信，請務必點擊「最新發出的那一封」，或在下方重試登入/發送。',
      ToastType.warning,
      actionLabel: '重發驗證信',
      onActionPressed: () => setState(() => _isSignUp = false),
    );
  }
  ```
