## 🎯 實作成果摘要
修復客戶管理頁面在手機版窄螢幕（寬度 < 768px）下，多選浮動操作列因按鈕過寬導致「建立專案」被裁切、「移至垃圾桶」與「關閉按鈕」被推擠至螢幕外的跑板問題。採用「方案 A（雙層等寬均分）」重構佈局，上層展示選取狀態與取消按鈕，下層以 3 顆等寬按鈕整齊並排並配置防溢出縮放，兼顧高專業性與舒適觸控體驗。

## 💻 技術變更明細 (Actual Technical Changes)
- **[MODIFY] [`lib/screens/customer_management_tab.dart`](file:///c:/Users/user/Documents/GitHub/project67/lib/screens/customer_management_tab.dart)**：
  - 重構 `_buildBatchSelectionBar(BuildContext context)` 支援 RWD 寬度判斷（`isWideScreen = MediaQuery.of(context).size.width >= 768`）。
  - **寬螢幕模式（>= 768px）**：維持原本單行橫排佈局，展示全選狀態、匯出選取、建立專案、移至垃圾桶及關閉按鈕。

    - **上層（狀態列）**：`Checkbox`（緊湊模式） + `已選 $selectedCount 位 / 共 $allFilteredCount 位` + `InkWell` 包覆之 `Icons.close`（✖）退出多選按鈕。

  - 核心程式碼片段：
    ```dart
    isWideScreen
        ? Row(children: [ ... ])
        : Column(
            mainAxisSize: MainAxisSize.min,
            children: [
              Row(
                children: [
                  Checkbox(value: isAllSelected, visualDensity: VisualDensity.compact, ...),
                  const SizedBox(width: 6),
                  Expanded(child: Text('已選 $selectedCount 位 / 共 $allFilteredCount 位', ...)),
                  InkWell(onTap: onExitSelection, child: const Icon(Icons.close, ...)),
                ],
              ),
              const SizedBox(height: 10),
              Row(
                children: [
                  Expanded(child: ElevatedButton(... child: Row(children: [Icon(...), Flexible(child: FittedBox(child: Text('匯出')))]))),
                  const SizedBox(width: 8),
                  Expanded(child: ElevatedButton(... child: Row(children: [Icon(...), Flexible(child: FittedBox(child: Text('建立專案')))]))),
                  const SizedBox(width: 8),
                  Expanded(child: ElevatedButton(... child: Row(children: [Icon(...), Flexible(child: FittedBox(child: Text('移至垃圾桶')))]))),
                ],
              ),
            ],
          )
    ```
