# 📅 [2026-09-22] - 【模組四：排程、日曆與戰情中樞】行程關聯客戶儲存修復與手機底部抽屜重構

## 🎯 實作成果摘要
- 徹底修復建立/編輯行程時選取「關聯客戶」導致的 `Postgres 23514 (check_violation)` 報錯問題，前端全面對齊資料庫白名單約束 `customer_visit`。
- 全面優化手機端（`< 768px`）操作手感：行程表單與多站路線規劃全面升級為「底部抽屜 (Bottom Sheet)」，配置大拇指操作熱區、拖曳小把手、`viewInsets.bottom` 鍵盤自動推移，並補齊手機頂欄重新整理圖示與「手勢下拉更新 (Pull-to-Refresh)」。

## 💻 技術變更明細 (Actual Technical Changes)
- **[MODIFY] `lib/models/schedule_event.dart`**：
  - 新增靜態方法 `normalizeEventType(String? type, {bool hasCustomer = false})`，將前端傳入的 `'visit'` 自動歸一化為 `'customer_visit'`，將 `'reminder'` 歸一化為 `'follow_up'`。
  - 在 `toJson()` 與 `fromJson()` 中強制調用 `normalizeEventType`，確保送入 Supabase `schedule_events` 表的 `event_type` 100% 符合資料庫 CHECK 約束白名單：`{'personal', 'customer_visit', 'meeting', 'follow_up', 'general'}`。
- **[MODIFY] `lib/widgets/schedule_event_dialog.dart`**：
  - 新增 `isBottomSheet` 參數。在手機模式下渲染圓角底部抽屜，配置頂部灰色拖曳把手與 `padding.bottom: viewInsets.bottom + 20`，鍵盤彈起時自動推移，儲存按鈕永不被遮擋。
  - 修正 `_saveEvent()`：建立行程時若選擇關聯客戶自動傳遞 `'customer_visit'`；編輯現有行程時若補選關聯客戶，自動由 `'personal'` 升級為 `'customer_visit'`。
  - 地點輸入框後方「開啟地圖」按鈕加入 `suffixIconConstraints: BoxConstraints(minWidth: 42, minHeight: 42)` 與緊湊約束，窄螢幕下圖示永遠維持 22px 正方不變形。
- **[MODIFY] `lib/widgets/route_planner_dialog.dart`**：
  - 新增 `isBottomSheet` 參數。手機模式下改為滿版底部抽屜，導航按鈕改為滿版直排（`Column(crossAxisAlignment: CrossAxisAlignment.stretch)`），「取消」按鈕置於下方，徹底解決按鈕橫向擠壓跑版問題。
  - 頂部標題採用 `Expanded` 與 `TextOverflow.ellipsis`，確保長標題不推擠右側關閉「X」按鈕。
- **[MODIFY] `lib/screens/home_screen.dart`**：
  - 新增 `_openRoutePlannerDialog()` 響應式封裝方法，統一 3 處路線規劃呼叫點（手機開 BottomSheet，電腦開 Dialog）。
  - `_openAddEditEventDialog()` 整合 `showModalBottomSheet`。
  - 手機版頂部 AppBar 右側補上「重新整理」圖示按鈕（直達 `_fetchEventsForSelectedDate()`）。
  - 手機端行程視圖外層包覆 `RefreshIndicator`，並為所有空狀態與滾動視圖加上 `AlwaysScrollableScrollPhysics`，全面支援手勢下拉更新 (Pull-to-Refresh)。
