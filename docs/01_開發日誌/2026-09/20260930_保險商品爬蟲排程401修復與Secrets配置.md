## 🎯 實作成果摘要
- 排查並解決 GitHub Actions `Automated Insurance Products Crawler Cron` 排程因缺少 API Key 導致 Supabase Kong API 閘道回傳 `HTTP 401 Unauthorized` 的中斷問題。
- 補齊 GitHub Actions 呼叫 Supabase Edge Function (`crawl-insurance-products`) 必備的 `apikey` 與 `Authorization` 標頭，並支援環境變數優先與 Fallback 機制。

## 💻 技術變更明細 (Actual Technical Changes)

- **[MODIFY] `.github/workflows/crawl_insurance_cron.yml`**：
  - 新增 `SUPABASE_ANON_KEY` 環境變數對接與匿名金鑰 Fallback 設定。
  - 在 curl 請求中補上 `-H "apikey: ${ANON_KEY}"` 與 `-H "Authorization: Bearer ${ANON_KEY}"` 標頭，解決 Supabase 邊緣函式前置閘道驗證失敗問題。
  - 保留 `-H "x-crawler-secret: ${CRAWLER_CRON_SECRET}"` 標頭以完成 Edge Function 內部的排程安全性驗證。
  
  ```yaml
  ANON_KEY="${SUPABASE_ANON_KEY:-sb_publishable_hEIRyFKMgmbB2qVOVioGBQ_61oJxceL}"
  
  response=$(curl -s -w "\n%{http_code}" -X POST \
    "${SUPABASE_URL}/functions/v1/crawl-insurance-products" \
    -H "Content-Type: application/json" \
    -H "apikey: ${ANON_KEY}" \
    -H "Authorization: Bearer ${ANON_KEY}" \
    -H "x-crawler-secret: ${CRAWLER_CRON_SECRET}")
  ```
