# 📅 [2026-07-31] - 【模組一：基礎建設與安全防護】資料垃圾桶與相片自動清理實作

> **執行狀態**：🟢 已併入主線 (src)

## 🎯 實作成果摘要
- 實作了客戶與提醒的軟刪除（垃圾桶）功能，提供 30 天刪除警示、徹底刪除與復原機制，並設定 Supabase Trigger 與 pg_cron 排程，當資料徹底刪除或更新照片時，自動清空雲端 Storage 對應的照片檔案，防杜儲存空間膨脹，且解決了 Windows 本地 Puro 環境 Web 預覽之編譯路徑解析錯誤。

## 💻 技術變更明細 (Actual Technical Changes)

- **[DB] `supabase_schema.sql`**：
  - 新增 `customers` 與 `reminders` 的 `deleted_at TIMESTAMPTZ` 軟刪除欄位。
  - 啟用 `pg_cron` 延伸套件並排程 `purge-deleted-data-daily` 每天午夜清除已刪除 > 30 天的資料。
  - 新增三個 Trigger 聯動清理 `storage.objects` (儲存桶 `customer-photos` 與 `avatars` 的實體照片檔案)：
    - `trigger_delete_customer_photo`：實體硬刪除客戶時清理。
    - `trigger_delete_old_customer_photo`：更新或清除客戶頭像時清理舊檔。
    - `trigger_delete_old_avatar`：更新個人頭像時清理舊檔。

## 🚦 團隊協作與驗證指南 (Verification Plan)
- **工程師驗飾**：
  - 本地執行 `run_local_web.bat` 一鍵啟動預覽，前往 **[http://localhost:8080](http://localhost:8080)**。
  - 在「客戶管理」中軟刪除一個客戶，檢查是否有 Toast 彈出，並確認主列表已被隱藏。
  - 點擊 Toast 或從 Sidebar 進入「垃圾桶」，確認軟刪除客戶正確出現在列表且顯示剩餘天數。
  - 點選「復原」檢查客戶是否重回主列表；點選「徹底刪除」檢查該記錄是否永久清除，且 Supabase Storage 照片實體已被觸發清除。
- **PM/夥伴預覽**：
  - 直接執行 `run_local_web.bat` 即可不報錯一鍵啟動網頁預覽。
