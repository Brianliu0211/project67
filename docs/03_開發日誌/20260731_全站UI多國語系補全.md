## 🎯 實作成果摘要
- 為專案全面導入多國語系 (i18n) 支援，除了使用者自行輸入的業務內容外，全站靜態 UI（包括側邊欄、設定頁面、今日行程的日曆週曆、客戶管理表單與卡片、個人帳號資料表單與 Toast 提示）均能完美且即時進行中/英文切換。

## 💻 技術變更明細 (Actual Technical Changes)

- **[MODIFY] `lib/main.dart`**：
  - 註冊 `flutter_localizations` Delegates 與 Locale 變數。
  - 於 `main()` 中呼叫 `initializeDateFormatting` 註冊 `'zh_TW'` 與 `'en_US'` 支援。
  ```dart
  void main() async {
    WidgetsFlutterBinding.ensureInitialized();
    await initializeDateFormatting('zh_TW', null);
    await initializeDateFormatting('en_US', null);
    await AppSettings.instance.loadSettings();
    runApp(const MyApp());
  }
  ```

- **[MODIFY] `lib/screens/home_screen.dart`**：
  - 側邊欄菜單項目改用 `context.l10n(...)` 動態讀取。
  - 重構 `_buildWeeklyCalendarStrip`，使用 `DateFormat.yMMMM(locale)` 與 `narrowWeekdays` 動態抓取 Locale 的星期字元 (如中文顯示「一、二...」，英文顯示「M、T...」)。
  ```dart
  final String localeStr = AppSettings.instance.language;
  final String monthString = DateFormat.yMMMM(localeStr).format(_selectedDate);
  final List<String> narrowWeekdays = DateFormat.E(localeStr).dateSymbols.NARROWWEEKDAYS;
  ```

- **[MODIFY] `lib/screens/customer_management_tab.dart`**：
  - 地毯式重構「搜尋欄 Placeholder」、「新增客戶按鈕」、「空狀態提示標題與指引」。
  - 「新增/編輯客戶」Dialog 內的所有 TextFormField 欄位 Label 與提示文字（客戶姓名、綽號、電話、信箱、標籤、備註）、清除照片、取消與儲存按鈕全部多語系化。
  - 「確認刪除客戶」對話框內確認標題、提示內容及取消與刪除按鈕多語系化。
  - 卡片正面/背面備註區域 `notes.isNotEmpty ? notes : context.l10n('customer_card_no_notes')` 以及備註標題 `Notes (綽號)` 與 Tooltip 放大詳情多語系化。
  - 「放大詳情 (Zoom Dialog)」內操作按鈕（撥打、郵件）、複製成功 Toast、未填寫警告及電話與標籤欄位多語系化。

- **[MODIFY] `lib/screens/profile_screen.dart`**：
  - 基本資料設定與商務名片設定欄位（姓名、電話、公司、職稱、網站、服務地址、簡介、大頭貼清除按鈕）完全替換為 `context.l10n(...)`。
  - 將儲存中、成功儲存（離線與線上）及載入/上傳失敗之 Toast 提示完全進行 i18n 響應。

- **[NEW] `lib/services/app_localizations.dart`**：
  - 建立免 Codegen 方案之 `AppLocalizations` 核心類別。
  - 實作自訂的 `AppLocalizationsDelegate` 與 `BuildContext` 的擴充方法 `context.l10n(...)` 進行極簡的 UI 字串獲取。

- **[NEW] `lib/l10n/app_zh.arb` & `lib/l10n/app_en.arb`**：
  - 建立標準的 ARB 國際化翻譯字典，保留專案規範文件完整性。
