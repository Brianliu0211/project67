## 💻 技術變更明細 (Actual Technical Changes)

### **[MODIFY] `lib/services/app_settings.dart`**
- 新增 `_isSidebarHoverExpandEnabled` 偏好欄位（`bool`）。
- 新增 getter `isSidebarHoverExpandEnabled`、`setSidebarHoverExpandEnabled(bool)` 方法。
- 擴充 `loadSettings()`、`_saveToLocalPrefs()`、`_syncWithCloudOnStartup()`、`_saveAndSync()`、`resetToDefaults()` 以覆蓋新欄位。
- SharedPreferences key: `prefs_sidebar_hover_expand`；Supabase user metadata key: `sidebar_hover_expand`。

```dart
Future<void> setSidebarHoverExpandEnabled(bool enabled) async {
  if (_isSidebarHoverExpandEnabled == enabled) return;
  _isSidebarHoverExpandEnabled = enabled;
  notifyListeners();
  await _saveAndSync();
}
```

### **[MODIFY] `lib/screens/home_screen.dart`**

- `_getLocalizedMenuTitle()` 補全「專案拜訪」與「垃圾桶」的 l10n 對應。

```dart
bool get _effectiveSidebarCollapsed {
  final bool isHoverExpandActive = AppSettings.instance.isSidebarHoverExpandEnabled;
  return _isSidebarCollapsed && !(isHoverExpandActive && _isSidebarHovered);
}
```
