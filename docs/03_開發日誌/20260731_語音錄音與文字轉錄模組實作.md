# 20260731 開發日誌：Phase 3 語音錄音與文字轉錄模組實作

## 📝 變更摘要

本次開發完成 **Phase 3：語音錄音與文字轉錄** 功能。業務員可在 App 客戶新增/編輯表單中，透過長按或點擊錄音，將拜訪備忘錄直接錄製為音訊，並由 Supabase Edge Function 結合 AI 引擎進行即時語音轉文字（STT），自動附加至客戶備註欄位。同時建立 `visit_logs` 資料表與自動記錄 Trigger，為未來的數據戰情室鋪路。

---

## 🛠️ 技術改動與實作細節

1. **引入跨平台錄音套件 (`record`)**
   - 於 `pubspec.yaml` 新增 `record: ^5.2.0`。
   - Web 端採用 MediaRecorder API (`audio/webm;codecs=opus`) 錄製音訊位元組。

2. **Supabase Edge Function (`transcribe-voice` / `rapid-responder`)**
   - 使用 Deno 建立 Edge Function 處理音訊 Base64 資料。
   - 採用 Groq Whisper (`whisper-large-v3-turbo`) 與 Gemini 2.0 Flash (`gemini-2.0-flash`) 雙軌轉錄引擎。
   - 處理跨網域 CORS Header 與 OPTIONS 預檢請求。

3. **Flutter 語音服務層 (`VoiceTranscriptionService`)**
   - 封裝錄音啟動、停止、HTTP 傳輸與 Blob 讀取邏輯。
   - 支援線上與離線模式感知降級。

4. **語音錄音 UI 元件 (`VoiceRecorderWidget`)**
   - 實現待機、錄音中、轉錄中、錯誤處理四種動態狀態。
   - 加入錄音時間計時器與紅色脈衝光暈動畫。
   - 轉錄成功後自動將文字附加至客戶對話框的 `notesController`，支援手動編輯。

5. **`visit_logs` 拜訪歷史日誌表與 Trigger 遷移 SQL**
   - 建立 `visit_logs` 資料表與 RLS 權限政策。
   - 撰寫 PostgreSQL Trigger (`trg_auto_visit_log`)，當 `reminders.is_completed` 設為 `true` 時自動同步至日誌表。

6. **文件與工具包同步**
   - 自動更新 `docs/工具包.md` 記載 `record` 套件與 Web 錄音技術細節。
