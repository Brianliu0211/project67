- **分支**：`feature/beast-schedule-map-route`
- **對應模組**：模組四 Phase 5 (排程與日曆)

## 🎯 變更項目與完成功能

### 1. 行程表單簡化
- **`ScheduleEventDialog` 介面重構**：刪除過度繁雜且使用率低的「行程類型」與「關聯客戶」下拉選單，簡化行程新增/編輯表單。
- **資料庫向下相容**：後端 `event_type` 預設收攏為 `'personal'`，相容 Supabase `schedule_events` 歷史數據。

### 2. 雙欄互動式地點選擇器 (`ScheduleEventDialog`)
- 點擊地點欄位右側 `Icons.map` 圖示時，彈窗寬度自 `480px` 平滑展開至 `960px` 雙欄 Layout（表單固定在左側不被遮擋）。
- 支援台灣在地地點搜尋 (`countrycodes=tw`) 與點擊地圖大頭針，自動填入完整台灣中文地址（如 `臺北市松山區南京東路五段59巷29弄35號`）。
- 新增 `latitude` 與 `longitude` 屬性支援，並於 `ScheduleEventDialog` 中實作 Supabase PGRST204 缺欄位自動降級保護（避免資料庫尚未 ALTER TABLE 時崩潰）。

### 3. 「今日行程」右上角「路線規劃 🚗」功能
- 於 `home_screen.dart` 今日行程頂部工具列新增「路線規劃」按鈕，主題色彩完全連動系統 `primaryColor`。
- 點擊彈出 `RoutePlannerDialog` 對話框，依開始時間排序展示當日行程，預設自動勾選包含地點的行程。
- 按下導航按鈕後，透過免 API Key 官方 URL Scheme 跳轉至 Google Maps：
  - **起點**：自動鎖定為使用者 **「目前位置」**。
  - **停靠點與終點**：依時間順序將選定行程安排為 `Waypoints` 與 `Destination`，自動規劃完整駕車路線。
