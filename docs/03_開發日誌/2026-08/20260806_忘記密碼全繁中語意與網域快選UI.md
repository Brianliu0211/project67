# 📅 [2026-08-06] - 【模組二：帳號驗證與個人偏好】忘記密碼對話框 100% 繁中語意化、常用信箱網域快選選單與重設轉址修復

> **執行狀態**：🟢 已併入主線 (src) / 特徵分支 `feature/beast-forgot-password-i18n`

## 🎯 實作成果摘要
本工作階段修復了忘記密碼 (Forgot Password) 對話框因 i18n 字典缺漏顯示英文原 Key 的問題，將所有標題、描述、輸入框標籤與驗證文字 100% 轉為繁體中文；並於登入頁面電子信箱欄位右上角新增「常用信箱網域 ▾」快捷選單（支援 Google, Yahoo, Outlook, iCloud 一鍵帶入與自動替換），同時優化忘記密碼按鈕間距與修復 Supabase Auth 密碼重設轉址 `http://localhost:8080` 之相容性。

## ⚠️ 環境異動與破壞性變更 (Environment & Breaking Changes)
- **Supabase 控制台設定提醒**：若需測試點擊 Email 信件重設連結，需至 Supabase 控制台 **Authentication -> URL Configuration** 將 **Site URL** 與 **Redirect URLs** 設為 `http://localhost:8080` 與 `http://localhost:8080/**`。
