## 🎯 實作成果摘要
- 新增全域 `ResponsiveLayout` 斷點工具庫，並對 `HomeScreen` 頂部選單、日曆 View Switcher 以及全站對話框 (`ScheduleEventDialog`, `BatchImportCustomersDialog`) 進行 RWD 響應式佈局重構與 `maxHeight` 動態限制，徹底防止窄螢幕 (手機端 `< 600px`) 的溢出黃黑警示條。

## 💻 技術變更明細 (Actual Technical Changes)

- **[NEW] `lib/widgets/responsive_layout.dart`**：
  - 建立 `ResponsiveBreakpoints`（Mobile `< 600px` / Tablet `< 1024px` / Desktop）與 `BuildContext` 擴充 `context.isMobile`。
  ```dart
  extension ResponsiveContextExtension on BuildContext {
    bool get isMobile => MediaQuery.of(this).size.width < ResponsiveBreakpoints.mobileMax;
    bool get isTablet => MediaQuery.of(this).size.width >= 600 && MediaQuery.of(this).size.width < 1024;
    bool get isDesktop => MediaQuery.of(this).size.width >= 1024;
  }
  ```

- **[MODIFY] `lib/screens/home_screen.dart`**：
  - 導入 `ResponsiveLayout`。在手機端（`context.isMobile`）將日曆 Header 的「日期選擇/回今日」與「日時間軸 / 月網格」視圖切換器改為兩列流式排版，擺脫原本手持時橫向擠壓溢出的問題。

- **[MODIFY] `lib/widgets/schedule_event_dialog.dart`**：
  - 為 `Dialog` 內層 `ConstrainedBox` 新增 `maxHeight: MediaQuery.of(context).size.height * 0.85` 限制與 `SingleChildScrollView` 包覆，解決手機喚出軟鍵盤時之高度溢出問題。

- **[MODIFY] `lib/widgets/batch_import_customers_dialog.dart`**：
  - 將固定寬高 (`860x680`) 重構為 `ConstrainedBox(maxWidth: 860, maxHeight: MediaQuery.of(context).size.height * 0.88)`，實現手機/平板動態自適應。
