# 🎙️ 語音錄音與文字轉錄架構方案 (Voice Recording & Transcription Architecture)

本文件針對語音輸入到文字轉錄的技術流程進行評估，解答「是否必須先將音檔上傳至 Supabase Storage，才能進行轉錄」的架構問題。

---

## 1. 核心結論：不需要先存到 Supabase Storage

**只有在您希望提供「語音回放（讓業務事後可以播放當初的錄音檔）」功能時，才需要上傳並永久儲存音檔。**

如果您的目的**僅僅是為了獲得轉錄後的文字與提取欄位**，音檔完全不需要寫入 Supabase Storage。我們可以直接透過記憶體/暫存檔傳遞，實現更快速、更省儲存空間的架構。

---

## 2. 三種可行的技術實現路徑對比

我們有以下三種設計模式來處理「錄音 $\rightarrow$ 轉錄 $\rightarrow$ 提取」：

### 方案 A：直接透過 Supabase Edge Function 轉發給 Gemini (最推薦 ⭐️)
由於 **Gemini 1.5 Pro / Flash 是原生多模態模型 (Multimodal)**，它能直接讀取音檔並同時進行「轉錄」與「JSON 結構化分析」。
*   **運作流程**：
    1.  手機 App 在本機錄音，結束後將音檔以二進位（Bytes）或暫存檔，直接透過 HTTP POST 傳送給 Supabase Edge Function。
    2.  Edge Function **不儲存音檔**，直接將音檔的 Byte Stream 併入 Prompt 傳送給 Gemini API。
    3.  Gemini API 處理完畢，直接回傳「轉錄逐字稿」與「結構化 JSON 欄位（姓名、標籤、時間）」。
    4.  Edge Function 將 JSON 結果回傳給手機 App，結束流程。
*   **優點**：
    *   **最省成本**：Supabase Storage 佔用量為 0，不需要定期清理音檔。
    *   **極速且安全**：API Key 安全地鎖在 Supabase 後端環境變數中，且只發生一次網路傳輸。
    *   **單次呼叫完成**：不需要分「先轉逐字稿、再做語意分析」兩步驟，Gemini 一次搞定。

---

### 方案 B：手機端本地即時轉錄 (On-device Speech-to-Text)
利用手機系統內建的語音識別引擎（iOS 的 SFSpeechRecognizer 與 Android 的 Google 語音辨識）。
*   **運作流程**：
    1.  使用者說話時，Flutter 透過 `speech_to_text` 套件直接在手機端即時產出文字。
    2.  說完後，App 將產出的**純文字**傳送給 Supabase Edge Function 呼叫 Gemini 進行 JSON 欄位提取。
*   **優點**：
    *   **零音檔傳輸**：完全不需要傳輸音檔，只傳純文字，頻寬消耗極低。
    *   **即時反饋**：使用者可以在螢幕上看到字一個個跑出來。
*   **缺點**：
    *   **跨平台精準度不一**：iOS 與 Android 內建的中文語音辨識率不同，且對於保險專業術語、中英文夾雜（例如：買了險種、體況名詞）的辨識效果較差。

---

### 方案 C：非同步上傳儲存再轉錄（適用於需要語音回放）
如果您希望客戶卡片上，永遠留有一個「播放當時錄音」的按鈕，就必須採用此方案。
*   **運作流程**：
    1.  App 將音檔上傳至 Supabase Storage 的 `voice-records` Bucket。
    2.  上傳成功後，資料庫寫入一筆資料，觸發 Database Webhook 或由前端通知 Edge Function。
    3.  Edge Function 從 Storage 讀取音檔網址，送給 Gemini 進行轉錄與分析。
*   **優點**：
    *   保留了原始語音資產，供業務代表日後聽取語氣、核對細節。
*   **缺點**：
    *   **儲存成本高**：音檔累積速度極快，需實作自動過期清理機制。
    *   **速度較慢**：多了上傳 Storage 的等待時間。

---

## 3. 巨獸專案的架構決策建議

為了**最快上線、最省伺服器成本、且維持高精準度**，建議採用 **【方案 A：Edge Function 記憶體轉發 Gemini 1.5】**。

### 🛠️ 技術實作細節 (方案 A)：
1.  **Flutter 端**：使用 `record` 或 `flutter_sound` 套件錄製輕量化的 `.m4a` 或 `.mp3` 音檔到手機暫存目錄（Temporary Directory）。
2.  **Edge Function 端**：
    ```typescript
    // Edge Function 範例偽代碼
    Deno.serve(async (req) => {
      const formData = await req.formData();
      const audioFile = formData.get("file") as File;
      const audioBytes = new Uint8Array(await audioFile.arrayBuffer());

      // 呼叫 Gemini 1.5 傳入音檔 Bytes 與 Prompt
      const geminiResponse = await callGeminiWithAudio(audioBytes, {
        prompt: "請轉錄此錄音，並提取出以下 JSON 欄位...",
        mimeType: audioFile.type
      });

      return new Response(JSON.stringify(geminiResponse), { headers: { "Content-Type": "application/json" } });
    });
    ```
