## 📦 專案相依套件 (Project Dependencies)

這些套件已記錄在 `pubspec.yaml` 中，若要在新環境開發，請執行 `flutter pub get` 自動安裝：

### 核心套件 (Core Packages)
* **`supabase_flutter`** (`^2.15.4`): 負責與 Supabase 後端進行連線、進行身份驗證及資料庫查詢。
* **`flutter_dotenv`** (`^6.0.1`): 用於安全載入本地環境變數 (`.env` 檔案)。
* **`shared_preferences`** (`^2.2.2`): 提供本地 Key-Value 偏好設定持久化儲存（主題顏色、深淺模式、客戶卡片/清單預設檢視）。
* **`cupertino_icons`** (`^1.0.8`): 提供 iOS 風格的圖標資產。
* **`image_picker`** (`^1.1.2`): 用於從本機相簿選取照片或拍照，支援跨平台（Web、iOS、Android 等）圖片選擇。
* **`flutter_localizations`** (`sdk: flutter`): 支援 Flutter 內建元件（例如日期選擇器、對話框）的多國語系翻譯。
* **`intl`** (`^0.20.2`): 處理專案的多國語系、日期與數值格式化。
* **`record`** (`^5.2.0`): 跨平台語音錄音套件（支援 Android、iOS、Web、macOS、Windows、Linux）。於 Phase 3 引入，用於客戶備註語音輸入功能，Web 端採用瀏覽器 MediaRecorder API，音訊格式為 `audio/webm;codecs=opus`，搭配 Supabase Edge Function 與 Gemini 2.0 Flash 進行語音轉文字（STT）。
* **`file_picker`** (`^8.0.0`): 跨平台本機檔案選擇器（支援 Web、Android、iOS、Windows）。於 Phase 1.5 批次匯入/匯出功能中引入，用於讀取使用者本機 CSV 或 Excel (.xlsx) 客戶資料表。
* **`csv`** (`^6.0.0`): 跨平台 CSV 解析與生成套件。支援解析異質 CSV 檔、UTF-8 / BOM 編碼處理與標準 CSV 匯入範本生成。
* **`excel`** (`^4.0.0`): 專門用於讀取與解構 `.xlsx` 試算表之 Dart 套件。用於 Phase 1.5 批次匯入解析 Excel 檔案工作表 (Sheet) 與儲存格資料。
* **`desktop_drop`** (`^0.4.4`): 跨平台實體檔案拖曳處理套件（支援 Web 及 Desktop 檔案拖放事件）。於 Phase 1.5 批次匯入對話框中引入，讓使用者可以直接將電腦中的 CSV / Excel 檔案拖拽至上傳視窗中自動解析。
* **`flutter_map`** (`^7.0.2`): 跨平台 OpenStreetMap 互動式地圖渲染套件（支援 Web、Android、iOS、Desktop）。於 Phase 5 引入，用於呈現行程大頭針標記、點選地圖選取經緯度、以及繪製行程順序連線。
* **`latlong2`** (`^0.9.1`): 幾何與經緯度計算工具套件。提供 `LatLng` 資料結構與兩點之間地理距離/方位角計算。
* **`http`** (`^1.2.1`): 輕量級 HTTP 請求套件。用於向 OpenStreetMap Nominatim API 發起免 API 金鑰的地點模糊搜尋與逆向地理編碼請求。
* **`url_launcher`** (`^6.3.0`): 跨平台系統 URL / App 外部跳轉套件。用於在行程地圖中點擊一鍵導航時，免 API 金鑰跳轉至裝置原生的 Google Maps 應用程式或網頁。

## 🌐 第三方開源服務與 API (External Open-Source Services & APIs)

專案中整合了以下免 API 金鑰之開放式開源地理資訊 (GIS) 服務：

1. **OSRM (Open Source Routing Machine) API**
   - **用途**：於 Phase 5 「行程地圖」中引入。傳入當日行程點位經緯度，實時計算並回傳沿著實際道路、公路與巷弄彎道的真實駕車導航幾何線段 (GeoJSON Polyline)。
   - **官方網站 / API 端點**：`https://router.project-osrm.org/route/v1/driving/`
   - **特點**：100% 免費開源、免 API 金鑰、不需綁定信用卡。

2. **OpenStreetMap Nominatim API**
   - **用途**：於 Phase 5 行程地點搜尋與地圖選點中引入。提供地點關鍵字模糊搜尋 (Geocoding) 與經緯度逆向轉換完整中文地址 (Reverse Geocoding)。
   - **官方網站 / API 端點**：`https://nominatim.openstreetmap.org/`
   - **特點**：100% 免費開源、免 API 金鑰、支援 `countrycodes=tw` 台灣區域精準過濾。
