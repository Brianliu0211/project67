## 📌 第一階段：前端託管與免費網址 (Cloudflare Pages)

Cloudflare Pages 會自動分配一個免費的二級網域（例如：`https://insurance-helper.pages.dev`），不僅免去了購買網域的年費，也省去了繁瑣的 DNS Name Servers 設定。

### 1. 連結 GitHub 專案
1. 註冊並登入 [Cloudflare 官網](https://www.cloudflare.com/)。
2. 在左側選單進入 **Workers & Pages** -> **Create Application** -> **Pages** -> **Connect to Git**。
3. 授權並選擇您本專案的 GitHub 倉庫 `Brianliu0211/project67`。

### 2. 配置建置設定 (Build Settings)
請在設定頁面填入以下參數，以確保 Flutter Web 能夠成功編譯：
* **Framework preset**: 選擇 `None`
* **Build command** (建置指令):
  ```bash
  flutter/bin/flutter build web --release --web-renderer canvaskit
  ```
  *(說明：Canvaskit 渲染器在處理名片 3D 翻轉與複雜 UI 時效能較佳。若注重首次載入速度，可改用 `--web-renderer html`)*
* **Build output directory** (輸出目錄):
  ```text
  build/web
  ```

### 3. 設定建置環境變數 (Build Environment Variables)
展開下方 **Environment variables**，新增以下變數以指示 Cloudflare 下載 Flutter SDK：
* Key: `FLUTTER_VERSION`
* Value: `stable`

### 4. 獲取您的專屬網址
1. 點擊 **Save and Deploy**，系統將開始進行首次編譯。
2. 編譯完成後，Cloudflare 會在專案頂端顯示您的免費網址，格式為 `https://<你的專案名稱>.pages.dev`。請記錄此網址，後續設定將大量使用。

## 📌 第二階段：Supabase 正式環境配置

為了防範開發期測試資料污染正式環境，上架前必須在 Supabase 建立一個全新的 Production 專案。

### 1. 轉移資料庫結構 (Schema)
1. 進入本機 Supabase 專案，匯出最新的 Schema。您也可以直接使用專案內的 [supabase_schema.sql](file:///c:/GitHub/project67/supabase_schema.sql) 檔案。
2. 在全新的 Supabase Production 專案的 **SQL Editor** 中，執行該 SQL 檔案，快速建立所有資料表（`profiles`, `customers`, `schedule_events` 等）並啟用 RLS 與觸發器。

### 2. 配置身分驗證 (Authentication) 網址
1. 在 Supabase Production 後台，進入 **Authentication** -> **URL Configuration**。
2. **Site URL**: 修改為您的 Cloudflare Pages 免費網址（例如 `https://insurance-helper.pages.dev`）。
3. **Redirect URLs**: 新增允許的重新導向網址（例如 `https://insurance-helper.pages.dev/**`），以便 Google OAuth 或 Email 登入成功後能順利跳回應用程式。

### 3. 設定 API 安全存取限制 (HTTP Referrers)
為防止他人盜用您的 `SUPABASE_ANON_KEY`：
1. 進入 Supabase 的 **Project Settings** -> **API**。
2. 在 **Rest API** 的安全設定中，啟用網址來源限制，僅允許來自您免費網域 `https://insurance-helper.pages.dev` 的請求。

## 📌 第三階段：AI 金鑰防護 (Gemini API Proxy)

> [!WARNING]
> **安全漏洞警告**
> Flutter Web 會將所有代碼編譯成 JavaScript。如果您在 Flutter 程式碼中直接寫入明文 `GEMINI_API_KEY`，任何人都可以透過瀏覽器的「開發者工具 (F12)」輕鬆提取您的金鑰，造成免費額度被惡意消耗。

### 💡 免費解決方案：透過 Supabase Edge Functions 進行代理
Supabase 提供免費額度的 **Edge Functions** (每月 100 萬次免費呼叫)，我們可以寫一個極簡的後端代理函數。

#### 步驟 1：在 Supabase 正式專案設定密鑰
1. 進入 Supabase 後台 -> **Project Settings** -> **Edge Functions**。
2. 新增秘密金鑰：
   * Name: `GEMINI_API_KEY`
   * Value: 填入您的 Gemini API 金鑰。

#### 步驟 2：部署 Edge Function (例如命名為 `gemini-proxy`)
這段後端 Dart/TypeScript 程式碼只接收前端傳來的錄音文字，並在後端附加 `GEMINI_API_KEY` 呼叫 Gemini，再將結果回傳：
```typescript
// supabase/functions/gemini-proxy/index.ts
import { serve } from "https://deno.land/std@0.168.0/http/server.ts"

const GEMINI_API_KEY = Deno.env.get('GEMINI_API_KEY')

serve(async (req) => {
  const { prompt } = await req.json()
  
  // 在後端發送請求給 Gemini，前端完全看不到 API Key
  const response = await fetch(`https://generativelabs.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=${GEMINI_API_KEY}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      contents: [{ parts: [{ text: prompt }] }]
    })
  })
  
  const data = await response.json()
  return new Response(JSON.stringify(data), {
    headers: { "Content-Type": "application/json" }
  })
})
```

#### 步驟 3：Flutter 前端修改呼叫方式
將原本直接呼叫 Gemini SDK 的地方，改為呼叫 Supabase 用戶端：
```dart
final response = await supabase.functions.invoke(
  'gemini-proxy',
  body: {'prompt': voiceTranscription},
);
```

## 📌 第四階段：數據備份策略（防範免費版風險）
